Best results

  1. Play MapleStory in windowed mode with the bottom EXP HUD visible.
  2. Share the game window, not this website tab.
  3. The tracker automatically locates the EXP label and the green brackets around the percentage.
  4. Check the green and blue highlights. A warning means the HUD or digits were not detected confidently.
  5. If detection fails, click Find EXP again, then optionally use the manual fallback hidden above.

Readings can still be wrong, especially at very small font sizes. Check them against the game and use manual correction if needed.

Privacy: Game screenshots stay in your browser and are processed locally using Tesseract.js. Downloading the OCR library requires internet access. Browser capture asks permission each session and may pause if the shared window is minimized. No injection, game memory access, or automatic game inputs. Screen-only operation does not guarantee compliance with game rules.
